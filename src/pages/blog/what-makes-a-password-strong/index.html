What actually makes a password strong

Strength is not about odd symbols. It comes down to length and randomness. Here is what matters, and how to get it without having to invent anything yourself.

Length beats complexity

A long password built from ordinary characters is harder to crack than a short one crammed with symbols, because every extra character multiplies the number of guesses an attacker has to make. Swapping a 3 for an E does almost nothing. Adding four more characters does a great deal.

Randomness is the other half

A password is only as good as it is unpredictable. Anything you pick by hand tends to fall into a pattern that cracking tools already expect: a name, a date, a keyboard run. A generator that draws from the browser's cryptographic random source sidesteps that. Open the password generator, set the length to sixteen or more, and let it choose.

You are not meant to remember it

Random passwords feel impractical because people try to memorise them, which is the wrong job for a person. Save each one in your browser or a password manager and let the machine hold it. The single password worth committing to memory is the one that unlocks the manager, and that one can be a long passphrase rather than a jumble.
