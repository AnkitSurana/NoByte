What Base64 is for, and what it is not

Base64 turns binary data into plain text so it can travel through channels that were built for text. It helps to know what that buys you, and what it does not.

What it does

Base64 rewrites any data using a small set of safe characters, so a file can sit inside something that only expects text: a JSON field, a data URL, the body of an email. The output runs about a third larger than the input, which is the price you pay for that safety.

What it is not

Base64 is not encryption. Anyone can decode it in a single step, so it hides nothing. If a value has to stay secret, it needs to be encrypted; encoding it only changes the alphabet, not the meaning. Treating Base64 as a way to obscure a password or a key is a common and costly mistake.

When to reach for it

Common cases are embedding a small image straight into HTML or CSS as a data URL, carrying binary inside a JSON payload, and reading the contents of a token, since many are Base64 for transport. For any of these, paste the text or drop the file into the Base64 encoder, which also offers the URL-safe variant when the result has to go into a link.
