How to lock a note behind a passphrase

Sometimes you want to write something down, or send it to someone, without leaving it readable to anyone in between. A passphrase can do that. Here is what encrypting a note really means, and how a browser does it without any of your text leaving the page.

What locking a note with a passphrase means

Encrypting a message turns readable text into a block of scrambled characters. The only way back to the original is the passphrase you chose. Anyone who sees the scrambled block without the passphrase gets nothing useful from it, and there is no button that reverses it for them.

That is the whole idea: the security rests on the passphrase, not on hiding the message. You can paste the encrypted block into an email, a chat, or a note in a shared document, and it stays unreadable until someone types the passphrase back in.

How the browser does it without uploading anything

Browsers ship with a proper cryptography library built in, called the Web Crypto API. The text encryptor uses it to do three things on your own device:

  • It turns your passphrase into an encryption key. A passphrase on its own is not a good key, so it is stretched with a function called PBKDF2 that runs 200,000 rounds. That slowness is on purpose: it makes guessing passphrases by brute force expensive.
  • It encrypts the text with AES-GCM, a standard that both scrambles the message and adds a check so tampering is detected.
  • It packs a random salt and a random starting value together with the result and prints the lot as one base64 block you can copy anywhere.

None of that needs a server. The passphrase is never stored and never sent, so there is nothing to leak later.

Where it is genuinely useful

It fits any time the channel is less private than the message. Sending a wifi password or a door code to a family member over chat. Keeping a few recovery notes in a document that other people can also open. Pasting a secret into a ticket that a wider team can read, where only the right person has the passphrase.

It is not a replacement for a password manager, and it is not meant for encrypting large files. It is the quickest way to make one piece of text readable to one person.

The one rule to remember

There is no recovery. Because the passphrase never leaves your device and is never stored, nobody, including this site, can unlock the message for you if you forget it. Choose a passphrase you can remember or record safely, and share it through a different channel from the encrypted block itself.

Try it

Open the text encryptor, type a message and a passphrase, and press Encrypt. To read one back, paste the encrypted block in, enter the passphrase, and press Decrypt. Everything happens in your browser, and you can read the code on GitHub.
