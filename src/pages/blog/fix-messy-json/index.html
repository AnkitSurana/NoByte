How to fix messy JSON and read the error

When JSON will not parse, the message you get back can be blunt. Here is how to make a file readable, and how to find the character that is actually breaking it.

Format first, read second

Minified JSON on a single line is hard to scan for a missing bracket. Formatting it adds indentation and line breaks so the structure becomes visible, which on its own often shows where a level was never closed. Paste your JSON into the JSON formatter and press Format.

What the common errors mean

Most parse failures come from a short list of causes:

  • A trailing comma after the last item in an object or array.
  • Single quotes where JSON requires double quotes.
  • A key that is not wrapped in quotes.
  • A bracket or brace that was opened and never closed.

The formatter points at the line and column where parsing stopped, which is usually right after the real mistake rather than on it.

Minify when you are done

Once the JSON is valid, you may want it small again for a config field or a request body. Minify strips the whitespace back out and leaves the smallest valid version of the same data.

Format, validate, or minify with the JSON formatter. Nothing is uploaded, so it is safe for config and data you cannot share.
