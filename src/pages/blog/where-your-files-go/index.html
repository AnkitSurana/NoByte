Where your files go when you use an online tool

Most tools that shrink an image or edit a PDF work by uploading your file to a server. NoByte does the work in your browser instead. Here is the difference, and why it is worth caring about.

Two ways a website can handle your file

When you hand a file to a website, the work happens in one of two places.

Usually it happens on the company's servers. Your file is uploaded, processed there, and sent back to you. Smallpdf and Online-Convert both work like this. There is a sound reason for it: doing the work on their own machines lets them offer features that would be hard to run on a phone or an older laptop. The cost is that a copy of your file has sat on a computer you do not control.

NoByte takes the other route. The browser you already have can do the work itself and hand the file back, without any of it being sent away. Nothing is uploaded, so no server is holding your document, and there is no copy to delete later.

What a deletion policy really covers

Most upload-based tools have a line in their policy saying files are removed after a set time. That is better than keeping them forever, but it still only describes what happens to your file once it has left your device. You are trusting that the deletion actually runs, and that nobody opened the file before it did. When the file never leaves your browser, none of that has to be taken on faith.

Being honest about the limits

Working in the browser has trade-offs, and it would be dishonest to hide them. Some jobs really do need a server, and NoByte leaves those out instead of faking them. There is no speed test, because a browser cannot measure a fast connection accurately. There is no live currency converter, because the free exchange-rate feeds update once a day and go stale.

Two tools reach the network because they have to. The DNS lookup has to ask a resolver, and the dictionary pulls its definitions from a public service. The privacy page lists both.

How to check it for yourself

This is the part an upload-based tool cannot offer. Open your browser's developer tools, switch to the network tab, and use any tool on the site. You will see the page load, and after that nothing that carries your file. The site is open source as well, so you can read exactly what each tool does. If anything here is wrong, the code will show it.

Every tool on NoByte works this way. Have a look through all the tools, or read the source on GitHub.
