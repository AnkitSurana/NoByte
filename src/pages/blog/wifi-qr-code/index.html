How to make a Wi-Fi QR code guests can scan

A Wi-Fi QR code lets someone join your network by pointing a camera at it, with no password to read out or type. Here is how to make one, and what the fields mean.

What the code actually holds

A Wi-Fi QR code is a short piece of text in a fixed format. It carries three things: the network name, the password, and the security type, written so a phone's camera recognises it as a network to join. It is not tied to any company or account. Any generator that follows the format produces a code that a modern iPhone or Android phone can read.

Making one

Open the QR code generator and pick the Wi-Fi tab. Type the network name exactly as it appears in your Wi-Fi settings, capital letters and all, then the password. Choose the security type; for almost every home network this is WPA. The code redraws as you type. Save it as a PNG to print or send, or as an SVG if you want it to stay sharp on a large poster.

The code is drawn in your browser, so the password you type is never uploaded.

Getting it to scan first time

A few things separate a code that scans instantly from one people have to fiddle with.

  • Keep the contrast strong. A dark code on a light background reads best; a pale code laid over a busy photo often fails.
  • Do not shrink it too far. Printed, it wants to be at least a couple of centimetres across.
  • Test it before you print a stack of copies. Open your phone camera and point it at the screen.

Where to put it

A fridge, a guest room wall, the back of a café menu, a page in a welcome folder. Because the code only holds your network details, there is no harm in someone seeing it once you have already let them into the building. Treat it the way you treat the password itself: fine for guests, not for a public street.
