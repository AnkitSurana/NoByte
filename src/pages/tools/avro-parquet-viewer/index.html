Files are decoded entirely in your browser — no uploads, no third-party services. .avsc is plain JSON. A .avro header holds a map of metadata carrying the schema and codec. A .parquet file ends in a Thrift-compact FileMetaData footer, from which the row count, the first column's compression codec, and the flattened schema are recovered and shown, here, rebuilt as a tree.
