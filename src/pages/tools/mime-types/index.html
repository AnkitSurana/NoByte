ExtensionMIME type
A MIME type (Multipurpose Internet Mail Extensions) is the label that tells a browser what kind of file it is receiving, like image/png or application/json. It is the value a server sends in the Content-Type header so the browser knows whether to show, play, or download the file. Search by file extension (like .png) or by type (like json) to filter the list, all in your browser, and click any row to copy its MIME type.
